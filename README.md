# Kid Apps

A collection of simple educational games for children:

* **Addition Grid** – Practice addition by filling in a grid.
* **Subtraction Grid** – Practice subtraction with a similar grid interface.
* **Number Ordering** – Arrange numbers in ascending or descending order.

All games are written in plain HTML, CSS and JavaScript and run in any modern browser.

## Usage
Open `index.html` in a browser. Use the navigation on the left to switch between the games.
